# GOES Level-2 Products

Each timestamp folder mirrors a corresponding entry under `IMAGES/<satellite>/<domain>/` and contains multiple Level-2 data renderings plus a `product.cbor` metadata file.

## Product Codes Encountered

| Code    | `abi_rgb` label                     | Description & usage                                                                                   |
|---------|-------------------------------------|-------------------------------------------------------------------------------------------------------|
| `ACHT`  | `Cloud_top_Temperature_(ACHT)`      | ABI Cloud Top Temperature. Useful for convective intensity monitoring and aviation icing diagnostics. |
| `ACHA`  | `AWG_Cloud_Height_Algorithm_(ACHA)` | ABI Cloud Top Height from the Algorithm Working Group. Supports convective cloud depth estimation.    |
| `DSI`   | `Derived_Stability_Indices_-_CAPE`  | Derived Stability Indices (e.g., CAPE). Key for severe weather nowcasting.                            |
| `TPW`   | `Total_Precipitable_Water`          | Column-integrated moisture content. Feed into flash-flood risk tools.                                 |
| `RRQPE` | `Rain_Rate_Per_Quarter_Hour`        | Rainfall rate / Quantitative Precipitation Estimate. Supports hydrologic monitoring.                  |
| `SST`   | `Sea_Surface_Temperature`           | SST quicklooks. Prioritize for marine operations.                                                     |
| `LST`   | `Land_Surface_Temperature`          | Continental thermal fields. Valuable for drought/heat analytics.                                      |

Counts represent grayscale PNGs (`G16_<code>_YYYY...png`/`G19_<code>_YYYY...png`). Each code is paired with matching `abi_rgb_*` renders (with and without `_map`).
