# Reference Implementation

This folder contains the earlier filesystem-first service planning docs and should be treated as reference material for migration, not the target platform architecture.

These documents still matter because they describe:

- the behavior of the current Python packages
- the operational assumptions of the existing repository
- migration inputs for the container-first object platform

They are no longer the canonical design for the next-generation system.

Use the v2 architecture set here for the target design:

- [Object Platform v2](../object-platform/README.md)
