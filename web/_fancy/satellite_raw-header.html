GOES Data Repository

This directory hosts downlinked GOES products captured via SatDump. Content is organized by product family so operators and visitors can locate the feeds they need quickly.

  • EMWIN/ — Emergency Managers Weather Information Network bulletins and graphics
  • IMAGES/ — GOES ABI quicklook imagery plus NWS LRIT charts
  • L2/ — Derived Level-2 geophysical fields (CAPE, TPW, rain rate, etc.)
  • Admin Messages/ — GOES operational notices
