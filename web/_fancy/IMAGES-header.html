GOES ABI Imagery

Quicklook PNGs and RGB composites produced from GOES ABI scans. GOES-19 is the current production feed; GOES-16/18 folders retain historical context.

  • GOES-19/Full Disk
  • GOES-19/Mesoscale 1–2 — sampled every few minutes.
  • GOES-16 — Legacy February–March 2025 coverage
  • GOES-18 — Limited full-disk captures forwarded from GOES-18
  • NWS/ — NWS forecast charts

Each timestamp folder contains ABI bands (G19_13_YYYYMMDDThhmmssZ.png), RGB composites, and a product.cbor metadata file. Preserve these .cbor files when copying imagery if you intend to use them in satdump-ui or other tools for processing satellite imagery as they contain important image metadata.
